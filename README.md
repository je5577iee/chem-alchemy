# 化學反應實驗室

把物質放進燒杯、選擇反應條件，看看會發現什麼新物質！從氫、氧、碳、鈉、鐵等 12 種物質開始，透過真實的化學反應，一路做出水、食鹽、硫酸、肥皂、酒精、小蘇打……收集完整本物質圖鑑。

適合國中理化、高中化學，可以當課堂活動、預習或複習。

**整個遊戲只有一個 `index.html` 檔案，不用網路、不用安裝、不用註冊，也不會蒐集任何個人資料。**

## 線上使用

👉 https://je5577iee.github.io/chem-alchemy/

## 離線使用

下載 `index.html`，用瀏覽器打開即可，完全不需要網路。電腦、平板、手機都能玩。

## 玩法

1. 從「我的物質」點選 1～2 種物質放進燒杯
2. 選擇反應條件：🧪 常溫、🔥 加熱點燃、⚡ 通電、☀️ 光照、⚗️ 催化劑
3. 按「開始反應！」
   - 成功：顯示**配平的化學方程式**、實驗現象，新物質加入收藏
   - 物質對了但條件不對：會提示「換一個反應條件試試看」
   - 不會反應：什麼事也沒發生

### 畫面左邊

- **我的物質**：目前收集到的物質，可以依類別篩選
- **下一個任務**：顯示還沒完成的下一個任務，可以直接看提示
- **實驗紀錄**：做過的反應方程式，最新的在最上面，方便複習

## 內容

- **59 種物質**：元素、氧化物、酸、鹼、鹽類、水溶液、有機物
- **74 個反應**：燃燒、化合、分解、電解、酸鹼中和、金屬置換、沉澱、光合作用、發酵、酯化、皂化……
- 重要的工業與生活反應：哈柏法製氨、接觸法製硫酸、氯鹼工業、奧士華法、石灰水檢驗二氧化碳、小蘇打火山
- 危險的反應會標示 ⚠️ 警語

## 任務

16 個任務，例如「把水拆開」、「石灰水變混濁」、「藍色沉澱」、「鐵變銅？」、「臭雞蛋」、「植物的魔法」、「自己做肥皂」、「閃電的禮物」。卡關時可以點「給我提示」，每個任務有兩段提示，從方向到具體做法。

## 圖鑑

依類別列出所有物質，點一下可以看說明、做出它的方法，以及它還能參加幾個反應。

## 教學建議

- **課堂競賽**：分組比賽，看哪一組在 15 分鐘內發現最多物質
- **反應類型整理**：請學生把發現的反應分類（化合、分解、置換、中和）
- **連結生活**：討論小蘇打為什麼能讓麵包膨脹、胃藥為什麼能中和胃酸
- **方程式練習**：先讓學生自己寫出方程式並配平，再到遊戲裡驗證

## 注意事項

- 遊戲中的反應僅供學習，**很多真實操作有毒或會爆炸，請勿自行嘗試**
- 為了讓遊戲好玩，條件經過簡化（例如「催化劑」代表各種催化劑或酵素，「通電」包含電解與放電）
- 進度只存在**那台裝置的瀏覽器**，換裝置或清除瀏覽器資料就會消失；圖鑑頁可以「重新開始」
- 若發現反應或說明有誤，歡迎提出 Issue
