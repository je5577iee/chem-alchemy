# 化學反應實驗室

一個任務一個反應！先選一個任務，再從實驗架上選兩種物質放進燒杯，按下「開始反應」，看看會冒泡、變色還是產生沉澱。成功後會顯示配平的化學方程式、實驗現象，以及生活中的例子。

適合國中自然（理化），可以當課堂活動、預習或複習。

**整個遊戲只有一個 `index.html` 檔案，不用網路、不用安裝、不用註冊，也不會蒐集任何個人資料。**

## 10 個任務

| # | 類別 | 任務 | 反應 |
| --- | --- | --- | --- |
| 1 | 生活中的化學 | 小蘇打火山 | CH₃COOH(aq) + NaHCO₃(s) → CH₃COONa(aq) + H₂O(l) + CO₂(g) |
| 2 | 生活中的化學 | 胃藥的祕密 | Mg(OH)₂(s) + 2HCl(aq) → MgCl₂(aq) + 2H₂O(l) |
| 3 | 生活中的化學 | 經典酸鹼中和 | HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O(l) |
| 4 | 實驗室製造氣體 | 製造二氧化碳 | CaCO₃(s) + 2HCl(aq) → CaCl₂(aq) + H₂O(l) + CO₂(g) |
| 5 | 實驗室製造氣體 | 檢驗二氧化碳 | CO₂(g) + Ca(OH)₂(aq) → CaCO₃(s) + H₂O(l) |
| 6 | 實驗室製造氣體 | 製造氫氣 | Mg(s) + 2HCl(aq) → MgCl₂(aq) + H₂(g) |
| 7 | 顏色變化 | 長出紅銅 | Fe(s) + CuSO₄(aq) → FeSO₄(aq) + Cu(s) |
| 8 | 顏色變化 | 紅褐色沉澱 | FeCl₃(aq) + 3NaOH(aq) → Fe(OH)₃(s) + 3NaCl(aq) |
| 9 | 顏色變化 | 藍色沉澱 | CuSO₄(aq) + 2NaOH(aq) → Cu(OH)₂(s) + Na₂SO₄(aq) |
| 10 | 顏色變化 | 白色沉澱 | CaCl₂(aq) + Na₂CO₃(aq) → CaCO₃(s) + 2NaCl(aq) |

物質和方程式都標示狀態：(s) 固體、(l) 液體、(g) 氣體、(aq) 水溶液。

有些任務不只一個答案，例如製造氫氣也可以用鋅或鐵，製造二氧化碳也可以用小蘇打或碳酸鈉，做出來時會另外說明。

## 玩法

1. 在任務列表選一個任務（可以照順序，也可以挑喜歡的先玩）
2. 看任務說明，從「實驗架」上點兩種物質放進燒杯。每個任務的實驗架只放這一關會用到的物質，加上幾個干擾選項
3. 按「開始反應！」
   - **成功**：燒杯冒泡、放熱、變色或產生沉澱，顯示方程式、現象和生活中的例子
   - **選錯了**：會給一個提示，再試一次
   - **再錯一次**：直接告訴答案，幫你放進燒杯
   - 如果選到的是**別的任務的反應**，會告訴你那是哪一個任務
4. 卡住的時候，也可以隨時按「💡 給我提示」
5. 完成的任務會在列表上打勾，可以隨時再玩一次

## 教學建議

- **先猜再做**：按下「開始反應」之前，請學生先猜會發生什麼事
- **寫方程式**：請學生先自己寫出方程式並配平，再到遊戲裡對答案
- **反應分類**：完成後請學生把 10 個反應分成酸鹼中和、產生氣體、置換、沉澱
- **連結生活**：討論胃藥為什麼能中和胃酸、水壺裡的水垢是什麼

## 注意事項

- 遊戲裡很多藥品有腐蝕性或危險性，**真的做實驗時一定要有老師在旁邊，請勿自行嘗試**
- 遊戲**只收錄任務會用到的反應**。選錯時沒有反應，不代表真實世界中這兩種物質不會反應
- 進度只存在**那台裝置的瀏覽器**，換裝置或清除瀏覽器資料就會消失；任務列表下方可以「清除完成紀錄」
- 若發現反應或說明有誤，歡迎提出 Issue
